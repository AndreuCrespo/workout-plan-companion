# Contributing

Thanks for contributing to Workout Plan Companion.

## Before you start

Read the approved [product brief](docs/product-brief.md), [visual system](docs/design-system.md), and [GitHub workflow](docs/github-workflow.md). The current app interface is Spanish; repository collaboration happens in English.

## Contribution checklist

- Create a focused branch from `main`.
- Keep sample data, domain models, repositories, components, and routes separated.
- Do not add secrets, external services, distribution builds, or medical claims.
- Run the relevant checks before opening a pull request.
- Describe the user impact, validation performed, and any follow-up work in the PR template.

## Code of conduct

Be respectful, constructive, and mindful that training, health, and privacy are personal topics.
